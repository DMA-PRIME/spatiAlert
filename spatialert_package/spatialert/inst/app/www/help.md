# spatiAlert — About

This page covers app info, citation, and contact details. For the full
walkthrough (data setup, weights choices, statistic guidance, worked
examples with diagrams, and troubleshooting), see
**spatiAlert_Getting_Started.pdf** included alongside this app in your
download, or the **Start Here** tab for a quick overview.

---

## About this app

| | |
|---|---|
| **App** | spatiAlert |
| **Version** | 0.1.0 |
| **Method** | Getis-Ord Gi* hotspot analysis |
| **Data privacy** | All analysis runs locally on your machine — nothing is uploaded to any server |
| **License** | MIT |

## Citation

If you use spatiAlert in a publication or report, please cite both the app
and the analysis it accompanies:

> **App:** Serman, E.A., Witrick, B., & Rennert, L. (2025). spatialert: Interactive
> Spatial Hotspot Analysis for Public Health. R package. https://github.com/DMA-PRIME/spatiAlert

> **Published analysis:** Clusters of Concern — Spatial Link between Childhood
> Undervaccination and Measles Outbreaks in South Carolina. Published May 20, 2026.
> *N Engl J Med* 2026;394:2479–2481. DOI: [10.1056/NEJMc2604004](https://www.nejm.org/doi/full/10.1056/NEJMc2604004)
